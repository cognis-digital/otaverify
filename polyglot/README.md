# Polyglot implementations

Parallel implementations of **otaverify** (Validate OTA update packages end-to-end: signature chains, rollback protection, anti-downgrade counters, and delta-patch integrity.) across 9 languages, for reference and cross-language benchmarking.

- `python/` — python implementation
- `go/` — go implementation
- `rust/` — rust implementation
- `typescript/` — typescript implementation
- `c/` — c implementation
- `cpp/` — cpp implementation
- `java/` — java implementation
- `ruby/` — ruby implementation
- `csharp/` — csharp implementation
